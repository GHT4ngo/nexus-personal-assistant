# Nexus Personal Assistant

Nexus is a personal assistant app for connecting everyday life, work, studies, family, email, calendar, tasks, travel, and important goals into one practical command center.

The project will be built in agile steps:

1. Get a small working version running.
2. Test it with realistic daily-life examples.
3. Improve it based on real use.
4. Add integrations and automation carefully.

See [PROJECT_GUIDELINES.md](PROJECT_GUIDELINES.md) for the project rules, MVP plan, safety principles, and backlog.
